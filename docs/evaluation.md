# Evaluation

The bundled evaluation is synthetic and measures the workflow, not clinical safety.

| Metric | Definition |
|---|---|
| Citation coverage | Cited checklist items / all items |
| Status accuracy | Cases matching expected workflow state |
| Critical recall | Critical source items recognized in teach-back |
| Abstention check | Insufficient answers routed for confirmation |
| Latency | Median and p95 deterministic evaluation time |
| Memory | Heap delta during the benchmark |

Production evaluation requires reviewer-approved sources, representative Vietnamese speech slices, OCR error slices, calibrated confidence, and supervised pilots.
